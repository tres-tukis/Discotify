# 🤖 Discotify

Discotify es un bot de Discord desarrollado en Kotlin utilizando JDA.

## ✨ Características

- ✅ Slash Commands
- ✅ Arquitectura modular
- ✅ Configuración segura mediante Properties
- ✅ Integración con Discord API

## 🚧 En desarrollo

- 🎵 Reproducción de música
- 📃 Cola de canciones
- ⏯️ Controles de reproducción
- 🎶 Integración con Spotify
- 🔍 Búsqueda automática en YouTube

## Tecnologías

- Kotlin
- JDA
- Gradle
- Git
- GitHub
